# Changelog

Notable changes to `aisdk/azure`. Release notes are also published at https://github.com/phpaisdk/azure/releases.

## v0.11.0 — 2026-10-31

- Requires `aisdk/core ^0.11.0` and `aisdk/openai-compatible ^0.11.0`. Upgrade SDK packages together; no other changes in this package.

## v0.10.0 — 2026-10-29

### What's new

- Request and response support for the 0.10 SDK, including the new agent, failover, caching and decision APIs in `aisdk/core`.

### Compatibility

- Works with `aisdk/core ^0.10.0` and `aisdk/openai-compatible ^0.10.0` where applicable. Upgrade SDK packages together.

## Earlier releases

See the [GitHub releases](https://github.com/phpaisdk/azure/releases) for versions before 0.10.0.
